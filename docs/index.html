    Method — how answers become A

    Each answer scores 0–3. Willingness = Q1–Q4 total ÷ 12; capacity = Q5–Q8 total ÷ 12. The governing score is s = min(willingness, capacity), the standard IPS rule that the more restrictive dimension wins.

    A(s) = 12 · (1.5 / 12)s  →  s = 0 gives A = 12 (very conservative), s = 1 gives A = 1.5 (aggressive)

    The mapping is log-linear because the optimal risky share y* = (E[rP] − rf) / (A·σP²) is inversely proportional to A, so equal score steps give proportional steps in risky exposure. The 1.5–12 range is a design calibration (textbook examples typically use A ≈ 2–4 for an average investor), not an empirically estimated scale.

    Data dictionary & sourcing
    • Source. Yahoo Finance via the open-source yfinance library, called server-side by a GitHub Actions job — no API keys, and your browser makes no market-data calls.
    • Refresh. Every Saturday 08:00 IST (after the US Friday close). Each instrument shows its own last close date; NSE and US markets close on different days and holidays.
    • Prices. Dividend- and split-adjusted closes. Bad ticks (a price that collapses and snaps back within days) are removed automatically and listed in the footer.
    • Returns. 1W/1M/3M/6M/1Y are simple returns versus the close on or before that many calendar days ago; YTD is versus the last close of the previous year; 3Y is annualized.

    • Basket index. Equal-weight, monthly-rebalanced index of the 12 stocks, starting at 1.00 in January 2005. USD sleeves are shown in USD on their cards and converted to INR everywhere else.

    Estimation Inputs

    Method — optimization, shrinkage and the complete portfolio

    Inputs. Weekly (Friday-close) INR returns over the common window; USD sleeves converted at USDINR, unhedged. Weekly sampling avoids the non-synchronous close problem (NSE closes ~10:00 UTC, US ~20:00 UTC), which biases daily cross-market correlations toward zero. Means and covariances are annualized ×52.

    Policy model. Sample means are shrunk with the Bayes-Stein estimator (Jorion, 1986) toward the mean of the global minimum-variance portfolio, and every sleeve is bounded to a 5–50% policy range, as an IPS would.

    μBS = (1 − φ)·μ̂ + φ·μ0·1,   φ = (N+2) / [(N+2) + T·(μ̂ − μ01)′ Σ̂−1 (μ̂ − μ01)]

    Textbook model. Raw sample means, long-only, weights in [0, 1] — the classroom formulation, shown for contrast. Its corner solutions illustrate why practitioners shrink estimates and impose ranges.

    Frontier. For 120 target returns between the MVP and the maximum-return portfolio the pipeline solves min w′Σw s.t. w′μ = target, Σw = 1, bounds. The ORP maximizes (w′μ − rf) / √(w′Σw) (12 random restarts). Validation gates fail the pipeline if weights do not sum to 1, the frontier is non-concave, or any grid point beats the ORP's Sharpe ratio.

    Complete portfolio. y* = (E[rP] − rf) / (A·σP²). If y* ≤ 1 the client lends at rf. If y* > 1 and borrowing is off, the client stays fully invested and moves up the frontier to the point maximizing U = E[r] − ½Aσ². With borrowing at rB = rf + spread, the efficient set is the kinked CAL: lending line → frontier → borrowing line tangent from rB (leverage capped at 1.5×).

    Risk-free rate. Trailing 12-month return of a growth-option liquid-fund NAV, which tracks 91-day T-bill yields.

    Method — VaR, Expected Shortfall, backtesting and stress

    Historical simulation. Today's weights applied to every daily return vector in the window (hypothetical P&L). h-day VaR uses overlapping compounded h-day returns. VaR = −q1−c; ES/CVaR = −mean of returns at or below that quantile.

    Parametric: VaR = −(μ·h + z1−c·σ·√h),   ES = −(μ·h − σ·√h·φ(z1−c)/(1−c))

    Kupiec proportion-of-failures test. With T days and x breaches at expected rate p = 1−c: LR = −2 ln[(1−p)T−xpx] + 2 ln[(1−x/T)T−x(x/T)x] ~ χ²(1). A small p-value rejects the VaR model. The Basel traffic light is reported on the last 250 days at 99%: green ≤ 4 breaches, yellow 5–9, red ≥ 10.

    Stress scenarios. COVID-19 and the 2022 rate shock use the live vehicles. For the 2008 window several vehicles did not exist yet, so documented proxies are used (gold futures × USDINR for Indian gold, ACWI for global equity, BND for global bonds, all converted to INR). No investable Indian bond series exists for 2008, so the Indian-debt shock is an explicit 0% assumption. A leveraged portfolio's borrowing leg is charged the cash return plus the borrowing spread over the window.

    Caveat. Daily returns mix markets that close at different times (NSE vs US), which understates daily diversification effects; the weekly correlation matrix is the better guide to true co-movement.

    Method — ratios and attribution
    Sharpe = (R̄p − R̄f)/σp · Sortino = (R̄p − R̄f)/σdown · Treynor = (R̄p − R̄f)/β · αJ = (R̄p − R̄f) − β(R̄m − R̄f) · TE = σ(Rp − Rm)

    All annualized from daily returns (means ×252, deviations ×√252). Downside deviation uses the risk-free rate as the target: √(mean(min(Rp − Rf, 0)²)). β is the slope of portfolio excess returns on Nifty 50 excess returns.

    Brinson-Fachler (per month). With portfolio weights wp,i, policy weights wb,i, sleeve returns Rp,i and segment benchmark returns Rb,i:

    Allocationi = (wp,i − wb,i)(Rb,i − Rb) · Selectioni = wb,i(Rp,i − Rb,i) · Interactioni = (wp,i − wb,i)(Rp,i − Rb,i)

    The Indian equity segment benchmark is the Nifty 50; every other sleeve is its own benchmark (passive ETF), and the cash segment is the liquid fund — so selection arises only from the stock basket and, if leveraged, from financing cost. Monthly effects are linked with Carino (1999) log-smoothing coefficients so they sum exactly to the cumulative active return.

    Method — drift, triggers and costs

    Each sleeve's holding compounds at its own daily INR return; the cash leg earns the liquid-fund return (or pays it plus the borrowing spread if levered). On each monitoring date the band strategy checks every sleeve: absolute bands trigger when |w − w*| exceeds the band in percentage points; relative bands when |w − w*| / w* exceeds the band in percent. When triggered, the whole portfolio is traded back to target.

    cost = c · Σi |V·wi − V·w*i|   (c in bp per rupee traded, one-way)

    Costs proxy brokerage, exchange charges, STT and bid-ask spread on ETFs and large caps. Capital-gains tax on rebalancing sales is not modeled — in a taxable Indian account it would further favour wider bands or rebalancing with new cash flows.

      Method — the simulation

      Annual arithmetic expected return μ and volatility σ default to the client's complete portfolio on the Allocation tab (ex-ante, policy or textbook model as selected). They are converted to lognormal parameters by moment matching so that the simulated simple returns have exactly that mean and variance:

      σln² = ln(1 + σ²/(1+μ)²),   mln = ln(1+μ) − σln²/2,   monthly: rt ~ N(mln/12, σln²/12)

      Each month the SIP is added at the start and the balance compounds by ert; the SIP steps up once a year. The target is inflated to nominal rupees at the chosen inflation rate. Because terminal wealth on each path is linear in the SIP, WT = ai + SIP·bi, the SIP that reaches the goal with confidence q is solved exactly as the q-quantile of per-path break-even SIPs (G − ai)/bi. Returns are i.i.d. — no regime shifts, fat tails or sequence-of-return clustering — and the 5,000 paths use a seeded PRNG so results are reproducible.
